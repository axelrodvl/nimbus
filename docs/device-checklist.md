# Чек-лист устройств (шаг 50)

Ручная проверка мобильной PWA. Автоматические проверки (unit, e2e в эмуляции Pixel 7 / iPhone 15) — в
`client/tests/e2e/mobile.spec.ts`; здесь то, что без настоящего устройства не проверить.

Устройства: **iPhone** (Safari во вкладке и установленное), **iPad**, **Android** (Chrome, установленное),
**macOS** (Safari «Добавить в Dock», Chrome), **Windows** (Edge/Chrome), **Linux** (Chrome).
Отметка в таблице: ✔ работает, ✖ не работает, — не применимо.

## Ограничения платформы

| Что | Платформа | Почему не исправить в PWA | Кто закрывает |
|---|---|---|---|
| Gapless-воспроизведение | iOS, Android, desktop | Один `<audio>` и смена `src`: между треками возможна пауза | Шаг 53 (нативный плеер), 55 (desktop) |
| Надёжный фон при заблокированном экране | iOS | Safari может остановить страницу; смена трека обязана идти синхронно в `ended` (сделано), но гарантий нет | Шаг 53 |
| CarPlay, Android Auto | iOS, Android | Нет веб-API | Шаг 53 |
| Фоновые загрузки при закрытом приложении | iOS, Android | Service worker не живёт в фоне достаточно долго; OPFS-загрузки идут только пока приложение открыто | Шаг 54 |
| Вибрация | iOS | `navigator.vibrate` не поддерживается | Шаг 53 (нативные haptics) |
| Системная кнопка «назад» | iOS standalone | Нет в оболочке — заменена жестом от края (приближение) | Шаг 53 |
| Постоянство хранилища | Safari | `persist()` может быть отклонён; данные чистятся через 7 дней без запуска | Шаг 54 |
| Перекодируемый поток: перезагрузка «застрявшего» элемента с позиции | все | Для `transcode` позиция задана адресом `?t=`; автоперезапуск только для `direct` | — |

## Дополнение шага 51

- Музыка играет из скачанного на устройство файла; перезапустить бэкенд (`docker compose restart nimbus`) — воспроизведение не прерывается, индикатор связи показывает «нет связи» и возвращается сам.
- Полный 30-минутный прогон `SOAK_MINUTES=30 just soak` на машине с Docker.
