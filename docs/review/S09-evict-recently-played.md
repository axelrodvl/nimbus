# S09 — Кэш вытесняет только что прослушанное «вне библиотеки» раньше старых файлов библиотеки

**Приоритет:** P3 · **Область:** `backend/crates/worker/src/cache.rs`, `backend/crates/db/src/repo/pins.rs` · **Зависит от:** —

## Проблема

`evict_cache` (коммит `0588ba5`) сортирует кандидатов по ключу `(в библиотеке?, last_played_at|completed_at, …)`:
**все** файлы вне библиотеки вытесняются раньше **любого** файла библиотеки. Защищены только закреплённые и
стримящиеся прямо сейчас (`activity.is_protected`).

Сценарий: пользователь слушает альбом из поиска (`play_requested`, в библиотеку не добавлял), сервер скачал его
треки; кэш переполнен → вытесняются файлы этого альбома, которые он слушал пять минут назад (кроме текущего), а
файл библиотеки, не игравший два года, остаётся. Следующий трек / повтор альбома снова качается из сети (а для
CUE-образа — снова ждёт полный образ, S04).

Кроме того, `pins::library_files` учитывает любой источник трека библиотеки (не только primary): резервный файл
другой раздачи считается «нужным библиотеке» и защищён лучше, чем реально слушаемый файл вне библиотеки.

## Текущее состояние (прочитай перед началом)

- `backend/crates/worker/src/cache.rs` — `evict_cache`, ключ сортировки.
- `backend/crates/db/src/repo/pins.rs` — `library_files`, `protected_files`.
- `backend/crates/worker/tests/cache.rs` — тест «сначала вне библиотеки» из `0588ba5`.

## Что сделать

1. «Свежее» (`last_played_at` или `completed_at` моложе `RECENT_GRACE` = 24 ч) — в одном ярусе с файлами библиотеки:
   ключ `(library || recent, last_played_at|completed_at, torrent_id, file_index)`.
2. `library_files` — только primary-источники треков библиотеки (`ts.is_primary`).
3. Константу и правило описать в модульном комментарии и в `docs/operations.md` (раздел кэша).

## Тесты (обязательные)

`worker/tests/cache.rs`:

- `recently_played_non_library_file_outlives_old_library_file`: файл вне библиотеки, игравший час назад, и файл
  библиотеки, игравший год назад; лимит позволяет оставить один → вытеснен файл библиотеки.
- `stale_non_library_file_goes_first`: файл вне библиотеки, игравший 2 дня назад, — вытесняется раньше библиотеки
  (поведение `0588ba5` сохраняется вне окна).
- `non_primary_library_source_is_not_protected_as_library`.
