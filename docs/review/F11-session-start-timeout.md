# F11 — Бесконечная заставка при первом входе, если сервер не отвечает

**Приоритет:** P3 (баг) · **Область:** `client/src/lib/auth/session.ts`, `client/src/lib/api/auth.ts` ·
**Зависит от:** —

## Проблема

`session.start()` без кэша сессии (первый запуск, после выхода, очищенные данные сайта) ждёт `GET /api/session` без
таймаута. Если соединение установлено, но ответа нет (сервер завис, обратный прокси держит запрос, бэкенд
перезапускается за прокси), `RequireSession` бесконечно показывает `Splash` (спиннер) — ни «не достучались», ни кнопки
«Повторить»: `unreachable` ставится только при ошибке `fetch`.

Наблюдалось при ревью 2026-11-20: `vite preview` проксировал `/api` на незапущенный адрес — запрос висел, страница
15+ секунд показывала только спиннер, без сообщений в консоли.

С кэшем сессии проблемы нет: оболочка рисуется из кэша, сверка идёт в фоне.

## Текущее состояние (прочитай перед началом)

- `client/src/lib/auth/session.ts` — `start`, `unreachable`.
- `client/src/lib/api/auth.ts` — `session()`.
- `client/src/components/session-routes.tsx` — `Splash`, `Unreachable`.
- Как устроены таймауты в других запросах: `client/src/lib/api/client.ts`, `requestPlay` (S06, `AbortController`).
- Тесты: `client/src/lib/auth/*.test.ts`, `client/src/components/shell.test.tsx`.

## Что сделать

1. `api.session(signal)` принимает `AbortSignal`; `start` обрывает запрос через `SESSION_TIMEOUT_MS` (≈ 10 с).
2. Таймаут без кэша → `unreachable = true` (экран «Сервер недоступен» с «Повторить»); с кэшем — как сетевая ошибка:
   остаёмся при кэше.
3. Через ~3 с ожидания `Splash` показывает подпись «Подключение к серверу…» (14 словарей), чтобы долгий ответ не
   выглядел зависанием.
4. Повторный `start()` («Повторить») отменяет прежний запрос, если он ещё висит.

## Тесты (обязательные)

- `session.test.ts`: `session()` не отвечает — через `SESSION_TIMEOUT_MS` (фейковые таймеры) `unreachable = true`,
  сигнал запроса оборван; с кэшем — статус из кэша, `unreachable = false`.
- `shell.test.tsx`: висящий `/api/session` — через 3 с у заставки подпись, после таймаута — «Повторить».

## Критерии приёмки

- `just check`, `just client-test` зелёные; новые ключи — во всех 14 словарях (`i18n`-тест).
