> A refreshed home screen with playlists and a longer recently played row, simpler track playback, and better RuTracker compatibility behind Cloudflare.

## ✨ New

- **Library** — the home screen now shows your playlists between "Recently played" and "Recently added".
- **Search** — RuTracker requests can use a custom user agent and extra headers, and a full browser cookie string is accepted, so sessions behind a Cloudflare check work.

## ⚡ Improved

- **Library** — "Recently played" on the home screen shows 6 albums instead of 4.
- **Player** — a single click anywhere on a track row starts playback; artist and album links in rows are desktop-only.
- **Library** — the home heading is branded with the Nimbus icon and is "Nimbus" in every language.
- **Settings** — dropdowns mark only the selected item with a check and fit the available screen height.
- **Settings** — the Downloads and search link is removed from Settings.

## 🐛 Fixed

- **Downloads** — albums with no tracks being added no longer show a stray verification progress bar.
- **Search** — a Cloudflare challenge from RuTracker now reports a clear error instead of a generic failure.

## ⚠️ Upgrade notes

- The "Ready to play" list is removed from the home screen.
