> A faster, smoother client: big libraries open quickly, the queue and search no longer flicker, and startup can no longer hang.

## ⚡ Improved

- **Library** — the home screen renders before all tracks are loaded; tracks are loaded and stored in chunks, so large libraries start faster.
- **Library** — the library filter keeps your typing responsive while the URL follows.
- **Player** — the queue panel only renders visible rows and mounts when opened, so long queues stay smooth.
- **Player** — hidden player parts no longer subscribe to playback progress.
- **Search** — previous results stay on screen while a refined query loads.
- **Library** — covers that failed to load are remembered, so going back shows a placeholder without flicker.
- **Backend** — session start now times out, and the splash screen shows a "connecting" hint instead of hanging.

## 🐛 Fixed

- **Offline** — queued actions are sent as soon as the live connection opens after coming back online.
