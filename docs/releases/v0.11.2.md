> Smoother navigation and search: no flicker when opening screens, and slow MusicBrainz no longer breaks a search.

## ⚡ Improved

- **Library** — artist, album, playlist and search screens open without a flash; loading skeletons now match the loaded layout and image placeholders appear only after a short delay.
- **Search** — the "MusicBrainz is slow" hint appears immediately, so the results no longer jump.

## 🐛 Fixed

- **Search** — leaving the search screen no longer cancels the pending MusicBrainz request, so coming back shows the result.
- **Library** — going back or forward restores the previous screen exactly as it was, without flicker.
