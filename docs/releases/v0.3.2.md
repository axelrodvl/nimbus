> A small fix release: a fresh install now serves the web app out of the box.

## 🐛 Fixed

- **Docker** — `./start.sh` on a fresh install started only the API (`/` returned 404): an empty `NIMBUS_WEB_DIR=` in
  `.env.example` overrode the web app path baked into the image. The line is now commented out.

## ⚠️ Upgrade notes

- On an existing install, remove the `NIMBUS_WEB_DIR=` line from your `.env`.
