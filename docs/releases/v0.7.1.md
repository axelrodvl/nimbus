> A client performance release: large libraries and offline downloads update more smoothly, plus two mobile fixes.

## ⚡ Improved

- **Library** — live updates from the server are batched, so big libraries stay responsive while many changes arrive at once.
- **Library** — lists, artist pages and track menus do less work, scroll more smoothly and use less memory.
- **Offline** — downloading for offline use updates progress without UI stutter.
- **Settings** — server settings load faster and are organized into separate sections.

## 🐛 Fixed

- **Player** — on iOS the lock screen shows previous/next track buttons instead of seek buttons.
- **Search** — on mobile the keyboard now opens immediately when the search palette is opened.
