> FlareSolverr now runs out of the box, so RuTracker gets past Cloudflare even with an older `.env`.

## ⚡ Improved

- **Docker** — FlareSolverr is always part of docker compose and Nimbus uses it by default (`http://flaresolverr:8191`); no `COMPOSE_PROFILES` or extra `.env` lines are needed. Jackett stays optional (`COMPOSE_PROFILES=jackett`).
- **Settings** — the RuTracker connection check is available only once a login and password or a cookie is set, and says what is missing otherwise.

## 🐛 Fixed

- **Search** — RuTracker no longer stops at the Cloudflare challenge on installs whose settings were saved before FlareSolverr existed: an empty FlareSolverr field now means the default address.

## ⚠️ Upgrade notes

- Use the new `docker-compose.yml` from this release (it starts the `flaresolverr` container). To turn FlareSolverr off, set `NIMBUS_FLARESOLVERR_URL=` (empty) in `.env`. If your `.env` has `COMPOSE_PROFILES=flaresolverr`, you can drop it.
