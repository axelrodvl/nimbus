> Fewer requests and less flicker: the server state of albums, pins and artists now comes with the sync, plus a new app icon and a tidier Settings screen.

## ✨ New

- **Settings** — the theme toggle and logout now live under Settings.
- **Docs** — new app icon: a blue music note on a dark background.

## ⚡ Improved

- **Library** — album download status, pin state and artist import state arrive with the library sync, so screens show them instantly without extra requests.
- **Library** — artist images are known up front and thumbnails are warmed up in advance, so missing images no longer cause repeated requests.
- **Player** — the player bar spans the full window width.
- **Downloads** — the album server-download button keeps its place (with a spinner) and remembers its status.
- **Library** — on desktop the logout button sits on the sync status row in the sidebar.

## 🐛 Fixed

- **Library** — opening a screen no longer fires needless requests or shows a flash of the import block on first paint.
