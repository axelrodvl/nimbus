> A tidier mobile layout with consistent page gutters, a restructured Downloads screen, and a one-command update script.

## ✨ New

- **Library** — playlist cards look like album cards and have a play button.
- **Library** — album Sources and Remove actions moved into a menu in the album header.
- **Docker** — `scripts/update.sh` restarts the stack only if newer published images exist; `scripts/update-and-restart.sh` always restarts from published images.

## ⚡ Improved

- **Downloads** — the screen is structured like Settings, shows used and free space for the server and device groups, and its list rows have wider, even insets on mobile; background tasks moved to Settings.
- **Player** — the "connecting" hint is hidden for downloaded tracks and debounced; track rows and disc headers align with the page gutter.
- **Library** — page side gutters are 20px, and album and artist cards and Settings rows line up with them.
- **Library** — the "needs check" warning appears on the Sources screen instead of the album header.
- **Backend** — the default MusicBrainz User-Agent includes a real contact address.

## 🐛 Fixed

- **Player** — choosing an item in a track row's menu no longer also starts playback.
- **Downloads** — list icons are top-aligned so insets are square on mobile.
- **Library** — album card text height flows so the status bar sits right under it.
