# Шаг 47 — Офлайн-треки: интерфейс и управление местом

**Фаза 2 · Зависит от:** 43, 46 · **Закрывает находку:** F4 (интерфейс)

## Зачем

Движок шага 46 умеет хранить и скачивать. Теперь пользователь должен этим управлять: кнопка
«Скачать» у трека, альбома и плейлиста, видимый прогресс, понятное состояние «доступно офлайн»,
экран с тем, что скачано и сколько занимает, настройки лимита — и библиотека, которая без сети
показывает, что можно слушать прямо сейчас.

## Текущее состояние

- `src/lib/offline/manager.ts` — `pin/unpin/isPinned`, `retry`, `setPaused`, `removeAll`, store `offlineStatus`, селекторы `trackOfflineState`, `albumOfflineState`, `playlistOfflineState`, настройки устройства, флаг `offline.supported` (шаг 46).
- Экраны и компоненты: `TrackRow`, `AlbumCard`, шапки альбома и плейлиста (шаги 39, 42), меню трека (41–42), экран «Загрузки» с вкладками (44), настройки с разделами-массивом и примитивами (43), `useOnline`/`OfflineNotice` (45).
- Плеер уже играет офлайн-файлы и пропускает недоступное без сети (шаг 46).
- Шаг 42 готов: плейлисты в store — селекторы `playlistCards` / `playlistCard(id | 'favorites')` (число треков, длительность, обложка), `usePlaylistTracks(id)` и `useFavorites()`; id плейлиста в клиенте — `number | 'favorites'` (`parsePlaylistRef` в `lib/api/playlists.ts`). «Скачать плейлист» опирается на них.

## Что сделать

Если `offline.supported === false` — ничего из перечисленного не отображается, кроме одной строки в «О приложении»: «Этот браузер не поддерживает хранение музыки на устройстве».

1. **Компонент `OfflineButton`** (`src/components/offline/`): круглая кнопка-иконка с состояниями
   `none` (стрелка вниз) → `queued` (часы) → `downloading` (кольцо прогресса, по нажатию — отмена) → `done` (галочка в акцентном цвете, по нажатию — меню «Удалить с устройства») → `failed` (восклицательный знак, по нажатию — «Повторить»);
   для альбома/плейлиста дополнительно `partial` (часть треков скачана — кольцо с долей). Подписи для экранных читалок на каждое состояние. Размеры: компактный (строка трека) и обычный (шапка).
2. **Где появляется:**
   - шапка альбома и шапка плейлиста (включая «Избранное») — закрепление сущности целиком, рядом текст «Скачано N из M · X МБ»;
   - строка трека: маленький индикатор состояния (всегда, если трек закреплён или скачан в составе альбома/плейлиста) и пункт меню «Скачать на устройство / Удалить с устройства» (закрепление отдельного трека);
   - карточка альбома в сетках — маленькая отметка «скачан» в углу обложки;
   - полноэкранный плеер и меню текущего трека — тот же пункт меню.
   Удаление трека, скачанного в составе закреплённого альбома: предложить «Снять закрепление альбома» (иначе сверка вернёт его).
3. **Библиотека без сети.** Когда `useOnline()` ложно:
   - треки/альбомы, недоступные офлайн, приглушены; запуск недоступного трека → подсказка «Нет связи. Трек не скачан на устройство»;
   - `PlayAlbumButton` и запуск плейлиста формируют очередь только из доступных треков;
   - на главной вместо «Готово к прослушиванию» — «Доступно офлайн».
   В любом состоянии сети: во вкладках библиотеки фильтр-переключатель «Только скачанные» (состояние — в URL).
4. **Вкладка «На устройстве» экрана «Загрузки»** (добавить в массив вкладок шага 44; показывается первой, когда нет сети):
   - сводка: занято / лимит / квота браузера (`ProgressBar`), число треков, состояние очереди («Скачивается 3, в очереди 41», «Пауза», «Нет места», «Нет связи», «Только по Wi-Fi»);
   - кнопки «Пауза / Продолжить», «Повторить неудавшиеся»;
   - активные загрузки с прогрессом; затем список закреплений (альбомы, плейлисты, отдельные треки) с размером и долей скачанного, действие «Удалить с устройства»; сортировка по размеру/дате.
   Виртуализация списка. Счётчик на вкладке — число активных и ожидающих.
5. **Раздел настроек «Офлайн на этом устройстве»** (добавить в массив разделов шага 43; настройки хранятся локально, действуют сразу, без сервера):
   - лимит места (`Slider` от 1 ГБ до квоты браузера, с отображением занятого);
   - одновременных загрузок (`NumberInput` 1…6);
   - «Только по Wi-Fi» (`Switch`; строка скрыта, если `navigator.connection` недоступен);
   - «Постоянное хранилище»: состояние `navigator.storage.persisted()` и кнопка «Запросить», пояснение про установку на домашний экран для iOS;
   - «Удалить всё скачанное» (подтверждение с объёмом).
6. **Уведомления.** Toast по завершении закрепления целиком («Альбом X доступен офлайн»), при остановке из-за места (с действием «Открыть настройки»), при окончательной ошибке трека. Не больше одного toast на закрепление; при массовых операциях — один сводный.
7. **Глобальный индикатор.** В боковой панели/шапке — компактный индикатор активных загрузок на устройство (кольцо с общим прогрессом, клик → вкладка «На устройстве»); скрыт, когда очередь пуста.
8. **e2e-доступ.** Убрать служебный `window.__nimbus.offline` из шага 46, если он больше не нужен тестам (сценарии переписать на интерфейс).
9. **i18n.** Все строки — во все 14 языков; размеры через общий `formatSize`.

## Тесты (обязательные)

Компонентные:
- `OfflineButton`: все состояния и действия по нажатию, доступные имена, кольцо отображает долю;
- шапка альбома: «Скачано N из M · X МБ» при частичном состоянии; строка трека: индикатор и пункт меню меняются по состоянию;
- удаление трека из закреплённого альбома предлагает снять закрепление;
- библиотека без сети: приглушение, подсказка, очередь только из доступного; фильтр «Только скачанные» и его состояние в URL;
- вкладка «На устройстве»: каждое состояние очереди своим текстом; сортировки; удаление закрепления;
- раздел настроек: изменение лимита/параллельности применяется к менеджеру; строка Wi-Fi скрыта без API; «Удалить всё» требует подтверждения;
- уведомления: один toast на закрепление; сводный при массовых; закрепление, начатое до перезагрузки страницы и завершившееся после неё, даёт ровно один toast;
- `offline.supported === false` → ни кнопок, ни вкладки, ни раздела.

E2E:
- альбом: нажать «Скачать» → кольцо прогресса → галочка → «Скачано 12 из 12» → офлайн → перезагрузка → альбом играет; соседний нескачанный альбом приглушён, его запуск показывает подсказку;
- плейлист закреплён → добавить в него трек (в сети) → трек скачался сам;
- вкладка «На устройстве»: пауза → прогресс стоит → продолжить → завершилось; удалить альбом → место освободилось, галочка исчезла;
- лимит: выставить 1 ГБ при моке с большими файлами (или уменьшить лимит служебно) → состояние «Нет места» и toast → увеличить лимит → загрузка продолжилась;
- «Только скачанные» в библиотеке показывает ровно скачанные альбомы;
- мобильный размер: кнопки достижимы, меню трека содержит пункт скачивания, вкладка «На устройстве» читаема.

## Критерии приёмки

```
just client-check && just client-test && just client-cov && just client-build && just client-e2e
```

Скриншоты (светлая/тёмная, 390 и 1440 px): шапка альбома во всех состояниях кнопки, вкладка «На устройстве», раздел настроек — **просмотреть** и исправить несоответствия общему стилю.

## Не входит в шаг

- Изменение движка (шаг 46), кроме исправления найденных дефектов (с тестом).
- Автоматическое скачивание всей библиотеки одной кнопкой — можно закрепить плейлист или альбомы; «скачать всё» не делаем (слишком легко забить устройство).

## Подводные камни

- Не путай с серверным «Скачать на сервер» (шаг 44): разные иконки и всегда явные подписи — «на устройство» / «на сервер». На экране альбома обе кнопки рядом должны читаться без подсказки.
- Кольцо прогресса на сотне строк: подписывай строку только на состояние своего трека и обновляй прогресс не чаще 4 раз в секунду (движок уже ограничивает) — иначе прокрутка списка во время загрузки альбома будет дёргаться.
- Размер альбома до скачивания неизвестен (сервер не сообщает размеры файлов в синхронизации) — до завершения показывай только число треков, размер — по факту.
- Состояние «нет связи» должно определяться доступностью **сервера**, а не только `navigator.onLine` (см. `useOnline`): в домашней сети без интернета приложение полностью работоспособно.

> Заметка шага 43: раздел «Офлайн на этом устройстве» — новая запись в массиве `SETTINGS_SECTIONS` (`client/src/screens/settings/settings-screen.tsx`) с `server: false` (работает без сети) и своим компонентом; строки — `SettingsSection`/`SettingsRow`, элементы — примитивы `src/components/ui`.
