# Шаг 09 — Фронтенд: поиск

**Зависит от:** 08
**Оценка:** 1.5 дня

## Цель

Поиск «как в Spotify»: командная палитра по `⌘K`/`Ctrl+K` и страница `/search?q=` с секциями «Артисты», «Альбомы», «Треки», данные — из `GET /api/search`. У каждого результата — кнопка «Добавить в библиотеку» (на этом шаге она вызывает Server Function-заглушку; реальное добавление подключит шаг 11 после бэкенда шага 10).

## Обязательно прочитать

`docs/web-inventory.md` — есть ли в next-beats свой поиск/палитра; если есть — переиспользовать разметку и стили.

## Что сделать

### 1. Получение данных

- Клиентский хук `hooks/use-search.ts`:
  - debounce 350 мс; минимальная длина запроса — 1 символ;
  - отмена устаревших запросов через `AbortController`;
  - кэш результатов в памяти на сессию (Map `q → SearchResponse`) — повторный ввод того же запроса мгновенный;
  - состояния: `idle | loading | success | error`; при `loading` показывать предыдущие результаты приглушёнными (не мигать пустотой);
  - вызов `api.GET("/api/search", { params: { query: { q, limit: 8 } }, signal })` напрямую в бэкенд (CORS уже настроен в шаге 03).
- Если бэкенд в шаге 07 реализовал SSE `/api/search/stream` (см. Журнал) — использовать его, чтобы секции появлялись по мере готовности. Иначе — обычный запрос.

### 2. Страница `/search`

- `app/search/page.tsx`: инпут сверху (синхронизирован с `?q=` через `router.replace` без перезагрузки), под ним:
  - **Лучший результат** — первый артист (большая карточка) + топ-4 трека рядом (как в Spotify), если есть оба;
  - **Артисты** — горизонтальный ряд круглых аватаров (фото у MB нет — используем инициалы на градиенте, детерминированном от mbid);
  - **Альбомы** — сетка карточек с обложкой (`cover_url`, fallback из шага 08), название, артист · год · тип;
  - **Треки** — список в стиле строки трека из next-beats: обложка альбома, название, артист, альбом, длительность (`mm:ss`).
- Пустое состояние, состояние ошибки (с текстом из `errors[]`), скелетоны при первой загрузке.
- Элементы, у которых `library_id != null`, помечены галочкой «В библиотеке» вместо кнопки добавления; клик по ним ведёт на страницу в библиотеке (`/artist/{library_id}`, `/album/{library_id}`) — сами страницы появятся в шаге 11, ссылки можно делать уже сейчас.

### 3. Командная палитра `⌘K`

- Глобальный слушатель клавиш в layout-провайдере. Модальное окно с инпутом и компактным списком (до 3 артистов, 3 альбомов, 5 треков), тем же хуком `useSearch`.
- Навигация стрелками, `Enter` — открыть результат (для элементов не из библиотеки — открыть `/search?q=` с этим запросом), `Shift+Enter` или кнопка `+` — добавить в библиотеку.
- Внизу — «Показать все результаты» → `/search?q=`.
- Доступность: `role="dialog"`, `aria-activedescendant`, фокус-ловушка, `Esc` закрывает.
- Можно использовать `cmdk` — если добавляешь зависимость, отметь в Журнале.

### 4. Кнопка «Добавить»

- Компонент `<AddToLibraryButton type="artist|album|track" mbid albumMbid? />`.
- Server Function `addToLibrary(input)` в `app/actions/library.ts` — **на этом шаге заглушка**: `throw new Error("not implemented")` → кнопка показывает toast (`sonner`) «Скоро будет». Интерфейс входа зафиксировать:
  ```ts
  type AddToLibraryInput =
    | { type: "artist"; mbid: string }
    | { type: "album"; mbid: string }
    | { type: "track"; mbid: string; album_mbid?: string | null };
  ```
- Оптимистичное состояние через `useOptimistic` (кнопка → спиннер → галочка/откат).

### 5. Навигация

Пункт «Поиск» в сайдбаре/навбаре (иконка `Search`), подсказка `⌘K`.

## Тесты

- Unit (если в проекте есть vitest — иначе Playwright с моком): `useSearch` дебаунсит и отменяет запросы.
- Playwright: замокать `GET **/api/search*` через `page.route` фикстурой `tests/fixtures/search-radiohead.json`; проверить, что `/search?q=radiohead` показывает три секции, `⌘K` открывает палитру, стрелки + Enter работают.

## Критерии приёмки

- `just web-check`, `cd web && pnpm build` проходят; Playwright-тесты поиска проходят.
- Ручная проверка с живым бэкендом: ввод «radiohead» показывает результаты за ≤ 4 с при холодном кэше, мгновенно — при повторе.
